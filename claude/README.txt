CLAUDE — README
================

Cách sử dụng
------------
1. Tải file `SKILL.md` trong thư mục này về máy.
2. Upload `SKILL.md` vào ứng dụng Claude để sử dụng Skill.
3. Khi muốn AI phân tích chat, gọi Skill bằng:

   @dating-chat-helper

4. Sau đó upload screenshot tin nhắn hoặc nhập trực tiếp đoạn chat cần phân tích.
5. Claude sẽ phân tích ngữ cảnh và đưa ra gợi ý phù hợp.

Lưu ý
-----
- `SKILL.md` là file Skill chính.
- Screenshot/đoạn chat là dữ liệu đầu vào để phân tích.
- Không cần copy toàn bộ nội dung Skill vào từng lần sử dụng.
